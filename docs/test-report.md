## กรณีขอบ
- ไฟล์ที่ไม่ใช่ PDF แต่ตั้งชื่อ .pdf → "ไฟล์นี้ไม่ใช่ PDF ที่อ่านได้ หรืออาจเสียหาย" ไม่ล่ม — ผ่าน
- ชื่อไฟล์ภาษาไทยปนอีโมจิ (`Bไทย😀.pdf`) — แสดงและรวมได้ — ผ่าน
- ช่วงหน้าว่าง / `abc` / `0-2` → ข้อความแจ้งเฉพาะกรณี — ผ่าน
- แท็บอยู่เบื้องหลังระหว่างแปลง: **พบบั๊ก** pdf.js ค้างเพราะ requestAnimationFrame หยุด → แก้โดยเรนเดอร์ด้วย `intent: 'print'` แล้วทดสอบซ้ำผ่าน

## มือถือ / การเข้าถึง
- ความกว้าง 375 px: `scrollWidth = clientWidth = 375` ไม่มีแถบเลื่อนแนวนอน; ภาพย่อ 2 คอลัมน์ — ผ่าน
- ปุ่มสูงอย่างน้อย 40–44 px; แท็บใช้ลูกศรซ้าย/ขวา Home End ได้; ทุกปุ่มมีกรอบโฟกัส
- การลากวางหน้ามีทางเลือกปุ่ม ← → ; การลากไฟล์มีปุ่ม "เลือกไฟล์"
- สีข้อความรอง `#5a5e55` บน `#faf7f0` ≈ 6.3:1, ปุ่มหลัก ≈ 7:1 (ผ่าน AA) ; มีโหมดมืด

## ยังไม่ได้ทดสอบ
- Firefox และ Safari (ทดสอบเฉพาะ Chromium) — ควรเปิดทดสอบด้วยมือ
- ไฟล์จริงขนาดใหญ่ (หลายร้อยหน้า) และไฟล์ที่มีรหัสผ่าน (โค้ดแจ้งเตือนไว้แล้ว แต่ไม่ได้ทดลองกับไฟล์จริง)
- การลากวางด้วยเมาส์จริง (ทดสอบผ่านปุ่มและการป้อนไฟล์ด้วยสคริปต์)

### ขั้นตอนทดสอบด้วยมือ (Firefox/Safari)
1. เปิดเว็บ → แท็บ "รวมไฟล์" → เลือก PDF 2 ไฟล์ → กด "รวมแล้วดาวน์โหลด" → เปิดไฟล์ดูจำนวนหน้า
2. แท็บ "จัดหน้า" → ลากภาพย่อสลับกัน หมุน ลบ → บันทึก → ตรวจผล
3. ทำซ้ำกับแท็บอื่น ๆ ตามตาราง F-03 – F-06
