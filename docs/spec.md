# สเปกเชิงหน้าที่ — LeafLoom

> เขียนด้วยคำของเราเองจากความรู้ทั่วไปว่า "ชุดเครื่องมือ PDF" ทำอะไร ไม่ได้คัดลอกข้อความ ภาพ หรือโค้ดของโปรแกรมใด

## ผู้ใช้และเป้าหมาย
คนทั่วไปที่ต้องจัดการไฟล์ PDF ง่าย ๆ (รวม แยก จัดหน้า แปลงรูป) โดย **ไม่ต้องอัปโหลดไฟล์ไปที่ใด** ทุกอย่างทำในเบราว์เซอร์ของตัวเอง

## ฟีเจอร์และเกณฑ์ยอมรับ

| รหัส | ฟีเจอร์ | เกณฑ์ยอมรับ |
|---|---|---|
| F-01 | รวม PDF | เลือกได้ ≥2 ไฟล์, เลื่อนลำดับขึ้น/ลง, ลบออกจากรายการ, กดรวมแล้วได้ไฟล์เดียวที่จำนวนหน้า = ผลรวม และเรียงตามลำดับที่ตั้ง |
| F-02 | จัดหน้า | เปิด PDF 1 ไฟล์ เห็นภาพย่อทุกหน้า หมุน 90° ลบ เลื่อนซ้าย/ขวา (และลากวางได้) แล้วบันทึกเป็นไฟล์ใหม่ตามที่จัด |
| F-03 | แยก/ดึงหน้า | พิมพ์ช่วงหน้า เช่น `1-3,5` ได้ไฟล์ที่มีเฉพาะหน้านั้น; หรือแยกทุกหน้าเป็นไฟล์ละหน้าในไฟล์ ZIP; ช่วงผิดรูปแบบหรือเกินจำนวนหน้าต้องแจ้งเตือน |
| F-04 | รูปเป็น PDF | เลือก JPG/PNG หลายรูป เรียงลำดับได้ เลือกขนาด A4 หรือเท่ารูป ได้ PDF ที่ 1 รูป = 1 หน้า |
| F-05 | PDF เป็นรูป | เลือกความละเอียดและชนิด PNG/JPG ได้ไฟล์ ZIP ที่มีรูป 1 รูปต่อหน้า |
| F-06 | ประทับหน้า | ใส่เลขหน้า (ตำแหน่งล่างกลาง/ล่างขวา) และ/หรือลายน้ำข้อความ (รองรับภาษาไทย) ความทึบปรับได้ |
| F-07 | ความเป็นส่วนตัว | ไม่มีการส่งไฟล์ผู้ใช้ออกจากเครื่อง (ตรวจจากแท็บ Network) |

## ข้อมูลเข้า-ออก
- เข้า: ไฟล์ PDF, JPG, PNG ที่ผู้ใช้เลือกหรือลากมาวาง
- ออก: ไฟล์ PDF/ZIP ที่ดาวน์โหลดลงเครื่อง ไม่เก็บไฟล์ไว้ในเบราว์เซอร์

## กฎ
- ไฟล์ที่เปิดไม่ได้ (เสีย หรือมีรหัสผ่าน) → แจ้งข้อความ ไม่ล่ม
- ไฟล์ PDF ที่มีรหัสผ่าน: ไม่พยายามปลดล็อก

## กรณีขอบ
ไม่ได้เลือกไฟล์, เลือกไฟล์ผิดชนิด, ไฟล์ใหญ่/หลายร้อยหน้า, ชื่อไฟล์ภาษาไทย/อีโมจิ, ลบทุกหน้าแล้วกดบันทึก

## สิ่งที่ไม่ทำ
OCR, บีบอัด, แปลง Office, ลายเซ็นดิจิทัล, ปลดล็อกไฟล์ที่ไม่รู้รหัสผ่าน, บัญชีผู้ใช้/คลาวด์
