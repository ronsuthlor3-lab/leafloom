# บันทึกการออกแบบ

## เอกลักษณ์
- **ชื่อ**: LeafLoom (leaf = แผ่นหน้า, loom = กี่ทอผ้า — "ทอหน้าเอกสารเข้าด้วยกัน") ไม่มีส่วนใดของชื่อต้นแบบ
  ชื่อสำรอง: Pagefold, Sheetwise, ใบงาน (Bai-ngan), Quireo — ผู้ใช้ควรค้นฐานเครื่องหมายการค้าของกรมทรัพย์สินทางปัญญาก่อนใช้จริง
- **โลโก้**: ใบไม้รูปหน้ากระดาษพับมุม วาดเป็น SVG เองใน `assets/logo.svg`
- **สี**: เขียวหมึก `#1f5f4a` + ส้มอำพัน `#d9822b` บนพื้นกระดาษอุ่น `#faf7f0`; มีโหมดมืด
- **ฟอนต์**: ฟอนต์ระบบ (ไม่ฝังไฟล์ฟอนต์)
- **เลย์เอาต์**: แถบเครื่องมือแบบแท็บด้านบน + พื้นที่ทำงานหนึ่งแผงต่อเครื่องมือ + กล่องลากวางไฟล์ ข้อความทั้งหมดเขียนใหม่

## สถาปัตยกรรม
หน้าเดียว HTML/CSS/JS ไม่ต้อง build ไลบรารีจาก CDN (เวอร์ชันแน่นอน):
- pdf-lib 1.17.1 (MIT)
- pdf.js 3.11.174 (Apache-2.0)
- JSZip 3.10.1 (MIT — เลือกใช้ภายใต้ MIT จากสัญญาคู่ MIT/GPLv3)

ไม่มีข้อมูลถาวร ยกเว้นจำแท็บล่าสุดใน `localStorage`

```
leafloom/
├── index.html  style.css  app.js
├── assets/logo.svg
├── docs/ spec.md feasibility.md design.md test-report.md
├── README.md  LICENSE
```
