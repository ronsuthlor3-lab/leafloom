# ความเป็นไปได้

| ฟีเจอร์ | ประเภท | หมายเหตุ |
|---|---|---|
| F-01 รวม | เบราว์เซอร์ล้วน | pdf-lib |
| F-02 จัดหน้า | เบราว์เซอร์ล้วน | pdf.js แสดงภาพย่อ, pdf-lib บันทึก |
| F-03 แยก | เบราว์เซอร์ล้วน | + JSZip |
| F-04 รูป→PDF | เบราว์เซอร์ล้วน | pdf-lib ฝัง JPG/PNG |
| F-05 PDF→รูป | เบราว์เซอร์ล้วน | pdf.js + canvas + JSZip |
| F-06 ประทับหน้า | เบราว์เซอร์ล้วน | ลายน้ำวาดบน canvas แล้วฝังเป็นภาพ เพื่อรองรับภาษาไทยโดยไม่ต้องฝังฟอนต์ |
| บีบอัด PDF | เบราว์เซอร์ล้วน (ยาก) | ผลไม่แน่นอน → ภายหลัง |
| OCR | เบราว์เซอร์ล้วน (หนัก) | tesseract.js → ภายหลัง |
| แปลง Word/Excel | ต้องมีเซิร์ฟเวอร์ | ภายหลัง |
| ปลดล็อกไฟล์ที่ไม่รู้รหัส | ทำไม่ได้/ไม่ควรทำ | หลบเลี่ยงมาตรการป้องกัน (ม.53/4) |

## MVP vs ภายหลัง
- **MVP**: F-01 – F-07
- **ภายหลัง**: บีบอัด, OCR, แปลง Office, PWA ใช้ออฟไลน์, ภาษาอังกฤษ

## ความเสี่ยง
- ไฟล์ใหญ่มากอาจกินหน่วยความจำ → เตือนเมื่อเกิน 300 หน้า
- ต้องโหลดไลบรารีจาก CDN ครั้งแรก (ใช้ออฟไลน์ไม่ได้ใน MVP)
- ไฟล์ที่ผ่าน pdf-lib อาจสูญเสียลายเซ็นดิจิทัลหรือฟอร์มบางชนิด → ระบุใน README
