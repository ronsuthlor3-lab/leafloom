# LeafLoom

<img src="assets/logo.svg" width="64" alt="">

ชุดเครื่องมือ PDF ที่ทำงาน **ในเบราว์เซอร์ของคุณทั้งหมด** — ไม่มีไฟล์ถูกอัปโหลดไปที่ใด

**ใช้งานออนไลน์:** https://ronsuthlor3-lab.github.io/leafloom/

| เครื่องมือ | ทำอะไร |
|---|---|
| รวมไฟล์ | รวม PDF หลายไฟล์ เรียงลำดับเองได้ |
| จัดหน้า | ดูภาพย่อ หมุน ลบ ลากสลับลำดับหน้า |
| แยก / ดึงหน้า | ดึงช่วงหน้า เช่น `1-3, 5, 8-` หรือแยกทุกหน้าเป็น ZIP |
| รูป → PDF | JPG / PNG / WebP เป็น PDF ขนาด A4 หรือเท่ารูป |
| PDF → รูป | ทุกหน้าเป็น PNG/JPG ที่ 72–216 dpi |
| เลขหน้า & ลายน้ำ | ใส่เลขหน้าและลายน้ำข้อความ (รองรับภาษาไทย) |

## วิธีใช้
- เปิดเว็บด้านบน หรือ
- ดาวน์โหลดโปรเจกต์แล้วเปิดผ่านเซิร์ฟเวอร์ในเครื่องใดก็ได้ (เช่น `python -m http.server` แล้วเข้า `http://localhost:8000`)
  การเปิด `index.html` ตรง ๆ แบบ `file://` ใช้ได้ในเบราว์เซอร์ส่วนใหญ่ แต่บางเบราว์เซอร์บล็อก worker ของ pdf.js
- ต้องต่ออินเทอร์เน็ตครั้งแรกเพื่อโหลดไลบรารีจาก cdnjs

**การสำรองข้อมูล:** แอปไม่เก็บไฟล์ของคุณไว้เลย ผลลัพธ์ทุกอย่างถูกดาวน์โหลดลงเครื่องทันที ต้นฉบับไม่ถูกแก้ไข

## แรงบันดาลใจและความแตกต่าง
แนวคิด "ชุดเครื่องมือ PDF ฟรีหลายอย่างในที่เดียว" ได้แรงบันดาลใจจาก PDF24 (ใช้ชื่อเพื่ออ้างถึงเท่านั้น)

- โครงการนี้ **ไม่มีส่วนเกี่ยวข้อง ไม่ได้รับการรับรองหรือสนับสนุน** จาก Geek Software GmbH หรือเจ้าของ PDF24; PDF24 เป็นเครื่องหมายของเจ้าของ
- เขียนใหม่ทั้งหมดจากสเปกเชิงหน้าที่ของเราเอง ([docs/spec.md](docs/spec.md)) **ไม่ได้ถอดโค้ด** และไม่มีโค้ด ข้อความ ภาพ ไอคอน หรือไฟล์ใด ๆ ของ PDF24

| | LeafLoom | PDF24 (ตามที่ทราบทั่วไป) |
|---|---|---|
| ชื่อ / โลโก้ / สี | LeafLoom, ใบไม้บนหน้ากระดาษ, เขียวหมึก + อำพัน | ของเจ้าของ |
| ที่ประมวลผล | เบราว์เซอร์ของผู้ใช้เท่านั้น | มีทั้งโปรแกรมเดสก์ท็อปและเครื่องมือออนไลน์ |
| ฟีเจอร์ | 6 เครื่องมือพื้นฐานด้านบน | มากกว่ามาก (OCR บีบอัด แปลง Office ฯลฯ) |
| ไม่มีใน LeafLoom | OCR, บีบอัด, แปลง Office, ลายเซ็น, ปลดล็อกไฟล์ | — |
| เทคโนโลยี | HTML/CSS/JS ล้วน + pdf-lib, pdf.js, JSZip | ไม่ทราบ (ไม่ได้ศึกษาภายใน) |
| สัญญาอนุญาต | MIT โอเพนซอร์ส | ฟรีแวร์ซอร์สปิด |

## ข้อจำกัดที่ทราบ
- PDF ที่มีรหัสผ่านจะเปิดไม่ได้ (ตั้งใจไม่ปลดล็อก)
- ไฟล์ที่ผ่านการแก้ไขอาจสูญเสียลายเซ็นดิจิทัลและฟอร์มบางชนิด
- เลขหน้าอาจอยู่ผิดขอบในหน้าที่ถูกตั้งค่าหมุนไว้ในไฟล์ต้นฉบับ
- ไฟล์หลายร้อยหน้าอาจใช้หน่วยความจำมาก
- ทดสอบแล้วบน Chromium; Firefox/Safari ยังไม่ได้ทดสอบ (ดู [docs/test-report.md](docs/test-report.md))

### แผนภายหลัง
บีบอัด PDF, OCR (tesseract.js), PWA ใช้ออฟไลน์, หน้าภาษาอังกฤษ, แปลง Office (ต้องมีเซิร์ฟเวอร์)
